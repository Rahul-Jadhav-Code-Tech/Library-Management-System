# Library Management System

## Project Description
The Library Management System is a simple C++ console-based application developed using Object-Oriented Programming concepts. This project helps manage books, members, and library operations such as issuing and returning books.

The system allows users to:
- Add new books
- Add library members
- Display all books
- Issue books
- Return books
- Search books by title or author

This project is useful for understanding basic OOP concepts like classes, objects, functions, vectors, and conditional statements in C++.

---

## Features

### Book Management
- Add new books with:
  - Book ID
  - Title
  - Author Name

### Member Management
- Add new library members with:
  - Member ID
  - Member Name

### Issue and Return System
- Issue available books
- Return issued books
- Prevent duplicate issuing

### Search Functionality
- Search books by:
  - Title
  - Author

### Display Records
- View all available and issued books
